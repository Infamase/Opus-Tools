# Opus Tools

A toolkit that makes Claude better at the three things it's weakest at in game
development: **3D models, sound, and animation**. It targets Blender + Godot 4 projects
and is meant to be installed once on the game-dev PC as a Claude Code plugin, so every
project can use it.

The core idea is to give Claude ways to see and hear what it makes. Every tool that
creates something is paired with one that renders or analyzes the result, so Claude can
check and fix its own work before handing it over.

**Status:** planning. See [PLAN.md](PLAN.md) for the full game plan: diagnosis, tool
catalog, architecture, roadmap, and open questions.
