# Opus Tools

A toolkit that makes Claude better at the things it's weakest at in game development:
**3D models, pixel art, animation, and sound**. It targets Blender + Godot 4 projects and
is meant to be installed once on the game-dev PC (Claude desktop app), so every project
can use it.

The core idea is to give Claude ways to see and hear what it makes. Every tool that
creates something is paired with one that renders or analyzes the result, so Claude can
check and fix its own work before handing it over.

The repo holds code only. Model weights, asset and sound libraries, and apps are listed
for manual download, never committed.

**Status:** planning. See [PLAN.md](PLAN.md) for the full game plan: target setup,
diagnosis, tool catalog, architecture, roadmap, and open questions.
